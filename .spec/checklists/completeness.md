# Checklist — Completeness (완전성)

요구사항이 빠짐없이 정의되었는가?

## 위자드 흐름

- [ ] CHK001 - 6단계 각각의 진입 조건과 이탈 조건이 명시되어 있는가? [Completeness, FR-01]
- [ ] CHK002 - "이전 단계로 돌아갈 수 있다"에서 Step 1까지 돌아갈 수 있는지, 데이터는 유지되는지 정의되어 있는가? [Completeness, FR-01]
- [ ] CHK003 - 위자드 중간 이탈(브라우저 닫기, 새로고침) 시 상태 보존 여부가 정의되어 있는가? [Completeness, FR-01]

## Step 1: 종목 입력

- [ ] CHK004 - 종목명 vs 종목코드 입력 구분이 명시되어 있는가? ("삼영전자" vs "005680") [Clarity, FR-02]
- [ ] CHK005 - 존재하지 않는 종목명 입력 시 에러 처리가 정의되어 있는가? [Completeness, FR-02]
- [ ] CHK006 - 자동완성/검색 제안 기능 포함 여부가 명시되어 있는가? [Completeness, FR-02]

## Step 2: 꼭지 선택

- [ ] CHK007 - "5~7개" 꼭지의 생성 기준이 명시되어 있는가? (어떤 로직으로 5~7개가 결정되는지) [Clarity, FR-03]
- [ ] CHK008 - 꼭지의 카테고리/분류 체계가 정의되어 있는가? (온디바이스AI, 전장, 재무 등) [Completeness, FR-03]
- [ ] CHK009 - 최대 5개 선택 제한의 UI 피드백이 정의되어 있는가? (6개째 선택 시 어떻게 되는지) [Completeness, FR-03]

## Step 3: 분석 결과

- [ ] CHK010 - "긍정/중립/부정 태그"의 판단 기준이 명시되어 있는가? [Clarity, FR-04]
- [ ] CHK011 - 핵심 포인트 "3~5개"의 결정 기준이 있는가? [Clarity, FR-04]
- [ ] CHK012 - 분석 결과에 대한 출처/근거 표시 여부가 정의되어 있는가? [Completeness, FR-04]

## Step 4: 용어 선택

- [ ] CHK013 - "어려운 용어"의 추출 기준이 정의되어 있는가? (누구 기준으로 어려운지) [Clarity, FR-05]
- [ ] CHK014 - "생활 비유"의 품질 기준이 있는가? (예: 콘덴서→저수지 수준) [Clarity, FR-05]
- [ ] CHK015 - 용어가 0개 추출된 경우 이 단계를 건너뛰는지 정의되어 있는가? [Completeness, FR-05]

## Step 5: 형식 선택

- [ ] CHK017 - 카드뉴스의 장수(슬라이드 수) 결정 기준이 있는가? [Clarity, FR-06]
