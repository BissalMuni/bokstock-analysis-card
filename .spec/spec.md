# Specification — bokstock-analysis-card

## 유저 스토리

### US-01: 종목 분석 시작
- **As a** 투자자
- **I want to** 종목명을 입력하면 분석 가능한 각도(꼭지)를 제안받고 싶다
- **So that** 어떤 관점에서 분석할지 빠르게 결정할 수 있다

### US-02: 분석 각도 선택
- **As a** 투자자
- **I want to** 제안된 꼭지 중 1~3개를 선택하고 싶다
- **So that** 내가 관심 있는 관점으로만 분석을 받을 수 있다

### US-03: 분석 결과 확인
- **As a** 투자자
- **I want to** 선택한 꼭지별 분석 결과를 확인하고 싶다
- **So that** 투자 판단에 필요한 정보를 얻을 수 있다

### US-04: 용어 해설 선택
- **As a** 투자 초보자
- **I want to** 어려운 용어에 대한 쉬운 설명을 선택해서 포함시키고 싶다
- **So that** 카드뉴스를 받는 사람도 쉽게 이해할 수 있다

### US-05: 출력 형식 선택
- **As a** 콘텐츠 제작자
- **I want to** 카드뉴스, 표, SNS 캡션 등 출력 형식을 선택하고 싶다
- **So that** 목적에 맞는 형태로 결과물을 받을 수 있다

### US-06: 최종 결과물 확인 및 활용
- **As a** 사용자
- **I want to** 최종 카드뉴스를 미리보기하고 복사/다운로드하고 싶다
- **So that** 바로 SNS나 메신저에 공유할 수 있다

## 기능 요구사항

### FR-01: 위자드 흐름
- 6단계 순차 진행: 입력 → 꼭지선택 → 분석확인 → 용어선택 → 형식선택 → 결과출력
- 이전 단계로 돌아갈 수 있다 (뒤로가기)
- 진행 바로 현재 단계를 시각적으로 표시한다

### FR-02: 종목 입력 (Step 1)
- 텍스트 입력으로 종목명 입력
- 빈 값 제출 불가
- 입력 후 "다음" 버튼으로 진행

### FR-03: 꼭지 선택 (Step 2)
- 5~7개의 분석 각도를 카드/칩 형태로 표시
- 각 꼭지에 label + 한 줄 설명
- 1~3개 복수 선택 가능
- 0개 선택 시 진행 불가

### FR-04: 분석 결과 리뷰 (Step 3)
- 선택한 꼭지별로 분석 결과 카드 표시
- 각 카드: 제목, 요약, 핵심 포인트 3~5개, 긍정/중립/부정 태그

### FR-05: 용어 선택 (Step 4)
- 분석 결과에서 추출된 어려운 용어 목록 표시
- 각 용어에 쉬운 설명 + 생활 비유 포함
- 체크박스로 카드뉴스에 포함할 용어 선택
- 전체 건너뛰기 가능 (선택사항)

### FR-06: 형식 선택 (Step 5)
- 출력 형식 옵션: 카드뉴스, 요약 표, SNS 캡션
- 라디오 버튼으로 단일 선택

### FR-07: 최종 출력 (Step 6)
- 선택한 형식에 맞는 결과물 렌더링
- 카드뉴스: 슬라이드 형태로 넘기며 확인
- 복사 버튼, 처음부터 다시하기 버튼

## 성공 기준

- 종목명 입력부터 카드뉴스 생성까지 6단계 이내 완료
- 각 단계 전환 시 300ms 이내 응답
- 모바일(375px)에서 모든 단계 사용 가능
